# Knowledge Guild RPG Agent Guide

Start with `WIKI_RULES.md`. Personal material lives only in `members/{member-id}/`; do not read or edit another member space unless the user explicitly asks to compare it. Keep project facts in `projects/`, drafts in `synthesis/`, and explicit agreements in `decisions/`.

Use `member-id` (lowercase letters, numbers, hyphens) as the stable identity. Before personal Wiki work, read that member's `PROFILE.md`, `CONTEXT.md`, and `WIKI_SCHEMA.md` when present. `PROFILE.md` is the detailed approved interview profile and `CONTEXT.md` is the concise every-run personal context; never silently merge either with a pre-existing root `CLAUDE.md`. After those inputs, also read the member root `CLAUDE.md` when present: it is the cross-agent Wiki operational contract created or explicitly migrated by personal Wiki initialization. When operating in `raw/`, `wiki/`, or `output/`, also read that layer's scoped `CLAUDE.md` when present. Member `CLAUDE.md` files supplement this repository guide and never replace it. Personal opinions, hypotheses, common facts, synthesis drafts, and official decisions must remain separate.

When the user says “인제스트해줘” about a raw source, follow `prompts/ingest.md` exactly: analyze before writing, ask its three questions one at a time, then show a preview and require approval.
