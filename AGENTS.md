# Knowledge Guild RPG Agent Guide

Start with `WIKI_RULES.md`. Personal material lives only in `members/{member-id}/`; do not read or edit another member space unless the user explicitly asks to compare it. Keep project facts in `projects/`, drafts in `synthesis/`, and explicit agreements in `decisions/`.

Use `member-id` (lowercase letters, numbers, hyphens) as the stable identity. Before personal Wiki work, read that member's `PROFILE.md`, root `CLAUDE.md`, and `WIKI_SCHEMA.md` when present. Root `CLAUDE.md` is the canonical every-run personal/operational context; read `CONTEXT.md` only when it is explicitly a legacy compatibility projection, never merge both silently. When operating in `raw/`, `wiki/`, or `output/`, also read that layer's scoped `CLAUDE.md` when present. Member `CLAUDE.md` files are cross-agent operational contracts; they supplement this repository guide and never replace it. Personal opinions, hypotheses, common facts, synthesis drafts, and official decisions must remain separate.
