# Wiki³ Compare

사용자가 명시한 참여자들의 관점을 특정 주제에 대해 비교하세요.

이 작업은 프로젝트 스킬 `$explore-member-wikis`를 사용합니다. 스킬의 범위 확인, 점진적 읽기, 근거 추적, 저장 형식을 따르세요.

## 시작 전 확인

1. `WIKI_RULES.md`와 `projects/PROJECT_CONTEXT.md`를 읽습니다.
2. 비교할 주제와 참여자 `member-id` 목록을 확인합니다.
3. 지정되지 않은 참여자의 개인 공간은 읽지 않습니다.
4. 지정된 참여자의 `WIKI_SCHEMA.md`와 `wiki/index.md`부터 읽고, 주제와 관련된 Wiki 문서만 점진적으로 읽습니다.
5. `PROFILE.md`와 `CONTEXT.md`는 역할·목표·프로젝트 전체 관점이 질문에 필요하거나 문맥 없이는 주장을 해석할 수 없을 때만 읽습니다.

## 비교 기준

- 공통점
- 차이점
- 서로 충돌하는 주장
- 각 참여자만 가진 관점
- 각 주장의 근거와 출처
- 추가 검증이 필요한 부분

자료가 없다는 것과 반대 의견을 가진 것을 구분하세요. 비교 과정에서 개인의 말을 하나의 팀 의견으로 합치거나 다수 의견을 공식 결론으로 만들지 마세요.

## 결과 저장

사용자가 저장을 요청하면 `synthesis/comparisons/YYYY-MM-DD-주제.md`에 저장합니다. 문서에는 비교 대상, 작성일, 실제로 읽은 문서, 읽지 않은 범위, 비교 결과, 근거, 열린 질문을 포함합니다.
