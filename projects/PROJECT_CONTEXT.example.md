# Project Context

## Project name

Example Knowledge Guild

## One-line description

A warm pixel village for scoped Wiki records.

## Problem

Teams need to distinguish common project facts from each participant's personal Wiki perspective.

## Target users

Project teams that want to interview contributors before representing their permitted records.

## Desired outcomes

Create a project building and evidence-bounded personal Wiki characters without promoting personal views to common facts or decisions.
