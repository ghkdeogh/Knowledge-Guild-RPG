# Knowledge Guild RPG Project Context

## Goal

Represent each permitted member Wiki as a data-based Guild avatar in a warm pixel village. The Mission Board explains common project context; Wiki-grounded dialogue, evidence navigation, and skills help users explore records without collapsing personal viewpoints into team decisions.

## Core question

How can a member move from a Guild avatar to a short, evidence-bounded answer and its source records with clear scope boundaries?

## Open extension

The project is designed for additional member directories, local deterministic retrieval, optional server-side LLM grounding, and open-source adaptation to other Wiki structures.

## Current status

The final technology choices, role taxonomy, governance policy, and deployment policy are not decided. A public repository activity date may change a visual pose only; it does not describe a person's actual intent, availability, or personality.
